Banco de vendas não configurado

A dashboard lê os pedidos de um banco Postgres no Supabase. Para ativar:

  1. Crie um projeto gratuito em supabase.com.
  2. No SQL Editor, rode o arquivo db/schema.sql do repositório.
  3. Em Authentication → Users, crie o usuário administrador e libere-o com o comando que está no fim do schema.sql.
  4. Em Project Settings → API, copie a Project URL e a chave anon public para supabaseUrl e supabaseAnonKey em site.config.json.

Depois do próximo deploy o site passa a registrar os pedidos e esta página pede o login.
