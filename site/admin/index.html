Área do administrador

Somente quem tem permissão de escrita no repositório da loja consegue entrar e publicar alterações. O acesso é feito com um token do GitHub.

Como criar o token
  1. No GitHub, abra Settings → Developer settings → Personal access tokens → Fine-grained tokens e clique em Generate new token.
  2. Em Repository access, escolha Only select repositories e selecione .
  3. Em Permissions → Repository permissions, marque Contents: Read and write.
  4. Gere o token, copie e cole no campo acima.

O token fica guardado apenas neste navegador e é enviado somente ao GitHub.
